# 数据库字段契约

原仓库没有找到模特相关的建表迁移；下表按 `model_management.py` 中的 SQL 访问整理，实际类型、主键和索引以生产数据库为准。

## `[模特信息]`

- `模特ID`：主键，整数。
- `模特编号`、`模特姓名`、`视频地址`、`状态`、`国家`、`等级`、`备注`、`上传人`：文本字段。
- `创建时间`、`更新时间`：时间字段。
- `视频地址` 保存以分号分隔的视频文件名。

## `[模特排队]`

- `排队ID`：主键，整数。
- `模特ID`：关联 `[模特信息].模特ID`。
- `部门`、`排队状态`、`备注`、`创建人`、`代排队`：文本字段。
- `视频已完成`：布尔/整数标记，`0` 表示未完成。
- `创建时间`：时间字段。

当前未完成队列使用 `排队状态 IN ('排队中','暂停') AND 视频已完成 = 0` 判断。建议为 `模特ID`、`排队状态`、`视频已完成`、`创建时间`、`创建人` 建立组合索引。

## `feishu_id`

通知逻辑会读取：

- `YONGHU`：姓名。
- `FeiShu_ID`：飞书收件人 ID。
