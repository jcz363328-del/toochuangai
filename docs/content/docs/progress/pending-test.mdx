# 待测试

- A+多图参考：添加多个“参考图反推”节点，每个节点上传或连接1张图；运行后检查各自文案，选择背景/主体/辅助元素/装饰/字体/质感并编辑，再连接到“文案组合生图”。确认只使用已选文字、取消和失败重试正常、刷新保留文案与连线，生成历史可从小哈A+画布入口查看。

- A+画布：从小哈A+分组进入，在功能模块中添加A+节点，将商品/参考图片按顺序连入，检查生成、失败提示、四页沃尔玛结果回传和刷新保存；确认普通画布与A+项目分开存放。
- 画布生图显示：生成配置的模型应显示 `gemini-nano-banana-2.1`、`gpt-image-2.6-flare`、`gpt-image-2.5-flare`、`gpt-image-2`、`grok-imagine-image-quality`，不应再出现 `qwen-image-3-pro`；选择后不会跳回 `gpt-image-2`，生成出的图片节点应正常显示，刷新后仍然可见。Seedream 仍应保留在生图模型中。
- OmniaKey 渠道：小哈配置接口会同时返回 OmniaKey 与 OpenRouter 两个渠道，除 Seedream 外的生图模型都走 OmniaKey；画布生图和图生图应正常出图，Seedream 仍走 OpenRouter。
- OmniaKey 图片编辑：带参考图编辑时应创建异步媒体任务并轮询结果，不能长时间无响应；参考图较大时应自动压缩后仍能成功出图。
- Nano Banana 选项命名：检查画布的模特高清、图片处理下拉以及产品图精修/局部瑕疵修复的选项，应显示 `Nano Banana 2.1`，不再出现 `Nano Banana 2`。
- 画布图片下载命名：导入的图片节点名称保留原始文件名；对原图执行模特扩图、模特高清等功能后，下载结果图片的文件名应为“原图文件名_功能名.扩展名”，例如 `IMG_1001_模特扩图.png`，原图改名后下载仍按原始文件名拼功能名。
- 公众人物任务确认：只有检测到疑似知名公众人物时才提示“疑似公众人物”，普通真人模特图应直接开始任务；模特高清不再无条件弹窗。首次生成和失败结果重试都应保持该行为；选择继续后才执行任务，选择取消则停止；检测接口连接失败、鉴权或额度异常时应安全停止。
- 公众人物检测兜底：带参考图生成或使用小哈图片功能时，不应再弹出“OpenRouter 请求失败，详细信息已记录在服务器”。Gemini 返回空结果或无效结果时会自动重试并改用 `openai/gpt-4.1-mini` 检测；两者都无法判断时弹出“疑似公众人物”确认框，由用户决定是否继续。

- 公众人物识别：选择含马云等知名人物的图片节点后点击“人物识别”，应创建并连接识别说明与文本生成配置；运行后应输出姓名、身份和依据，低置信度图片应明确无法确认而不是猜测。
- 批量高清大图翻页：打开一批高清结果中的任意大图后，左右按钮应按批次顺序循环切换图片、显示当前序号，并同步选中画布上的对应结果节点。
- 飞书内置浏览器粘贴兼容：复制图片后选中空图片节点或点击画布位置并按 Ctrl+V，应直接填充节点或创建图片节点，不再提示浏览器不支持读取剪切板。
- 飞书内置浏览器粘贴兼容：复制图片后点击无限画布目标位置并按 Ctrl+V，应直接创建图片节点，不再提示浏览器不支持读取剪切板。
- 无限画布定位粘贴：复制一张图片，先点击画布目标位置，再按 Ctrl/Cmd+V，应在点击位置创建图片节点；未点击画布时回退到画布中心，浏览器不支持或拒绝剪切板权限时应显示明确提示。
- 无限画布图片使用记录：小哈图片功能成功、普通文生图、带参考图的图片编辑以及图片重试成功后，`AI_TuPian` 应新增一条带当前账号、“无限画布-具体功能”、实际模型和成功张数的记录；生成失败或取消不应记为成功使用。
- 无限画布图片节点小哈功能：图片节点顶部可切换模特高清、即梦超清 8K、智能抠图、去睫毛、换姿势、换场景、扩图、单眼变双眼、换肤色、换瞳孔颜色、换眼型、侧面图和 AI 问答生图；普通处理模型只能选择 Nano Banana 2 或即梦 5 Pro；参考类功能未连接参考图时不可提交，连接后以当前图片为主体、连入图片为参考；扩图可分别设置上下左右像素并在右侧生成新结果节点。
- 小哈内嵌无限画布部署：生产构建的脚本、样式和图标应使用 `/infinite-canvas/` 子路径；本机和公开入口的脚本、样式请求均应返回 200，页面不应黑屏。
- 无限画布图片节点模特高清：图片节点操作面板的模型下拉直接作为模特高清入口，只能看到“Nano Banana 2 · 模特高清”和“即梦 5 Pro · 模特高清”；已有图片无需填写提示词即可提交，空图片节点应提示先上传或生成原图，两种模型的结果都应按原图尺寸生成在原节点右侧。
- 无限画布模特高清：底部“功能模块”可添加“模特高清”节点；只选中一张图片时应自动放置并连线，未选图片时可手动连线；填写补充要求不应丢失原图输入，处理结果应作为新图片节点出现在模块右侧，并保持原图尺寸与人物、肤色、色调和构图；从小哈入口新建、返回或切换画布时应持续保留访问凭证。
- 画布节点创建：鼠标左键双击画布空白区域会在点击位置打开节点选择菜单，可创建文本、图片、视频、音频、生成配置和组节点；双击已有节点或连线不应触发菜单。
- 本地 Agent 连接说明：新增提醒说明只有安装 Codex 插件或手动添加 MCP 后才会增加 Codex token 消耗，直接运行 `npm --prefix canvas-agent run dev` 不会安装 MCP；需验证文案位置清晰。
- 本地 Agent 连接说明：画布面板和配置页 Codex Tab 改为区分“Codex 插件启动画布”和“直接运行 Agent 后网页连接”两种方式，需验证文案和布局清晰。
- 全站 Agent：Agent 面板从画布页抽离为全站常驻面板，挂在全局布局右侧，开/关只挤压左侧内容不遮挡；顶栏和画布工具条各有一个开关按钮，需验证在首页、生图、视频、素材、提示词库、画布等页面都能打开面板并保持 SSE 连接不断开。
- 全站 Agent：新增 `site_navigate` 工具，Agent 可直接跳转 `/`、`/canvas`、`/canvas/:id`、`/image`、`/video`、`/prompts`、`/assets`、`/config`；导航直接执行不走工具确认，需验证跳转正确且面板不消失。
- 全站 Agent：画布工具（canvas_apply_ops 等）仅在当前处于画布页时可用，不在画布页调用会返回“当前不在画布页，请先用 site_navigate 打开画布”，需验证 Agent 会先导航到画布再执行画布操作。
- 全站 Agent：Codex 会话改为单一站点级连续线程（不再按 canvasId 分），跨页面/跨画布保持同一条对话上下文，历史记录即这条线程；本地 Agent workspace 从按画布分改为固定 `site` workspace（`~/.infinite-canvas/codex-workspaces/site`），已装旧版本地 Agent 的用户需更新到新版本才生效。
- 全站 Agent：移除仅前端调用 OpenAI responses 接口的在线画布助手死代码（含 `requestToolResponse`），Agent 统一走 MCP + 本地 Codex 链路。
- 画布节点名称：每个节点保留 `title` 名称字段，默认名称显示在节点上方，双击名称可直接编辑，节点信息弹窗和 JSON 可查看该字段。
- 画布节点工具条：节点顶部工具条改为点击选中节点后显示，单纯鼠标移入 / 移出节点不应再频繁弹出。
- 画布组节点：组内子节点优先响应点击和拖拽；当鼠标位于组内节点上时，应移动 / 编辑该节点，而不是移动整个组。
- 画布组节点：工具栏新增“组”节点，普通节点拖入组区域会高亮目标组，松手后自动吸附进组；拖出组区域会解除归属，拖动组节点会一起移动组内子节点。
- GitHub Pages：新增版本 tag 触发的前端静态站点自动发布 workflow，需在仓库 Pages 设置中选择 GitHub Actions 并验证路由刷新回退。
- 画布图片切图：行数 / 列数会生成可直接拖拽的等分切图线，并支持新增横向 / 纵向线、删除单条线、重置切图线和切片数量预览。

- 画布 Agent：Codex 旧 thread 在重启后不可用时会自动新建会话并重试，需验证进入画布直接发送消息不会再出现 `thread not loaded` 或 `no rollout found`。

- 配置与用户偏好：每个模型渠道新增 OpenAI / Gemini 调用格式选择，默认 OpenAI，切换默认格式时同步更新默认 Base URL；渠道 Tab 增加紧凑醒目的提醒，说明模型是否可选需要到“模型”Tab 选择。
