# 图创 AI 本地启动

这份说明适用于 Windows 本地开发。启动脚本需要项目根目录的 `.env`、已安装依赖的 `.venv` 和 `.venv-xiaoha`，以及可从 PowerShell 调用的 Node.js。

主站的 Python 依赖见 [requirements.txt](requirements.txt)。如果需要补装，从项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r docs\requirements.txt
```

## 启动

在项目根目录打开 PowerShell，运行：

```powershell
.\.venv\Scripts\python.exe scripts\local_services.py start
```

脚本会依次启动主站、小哈、画布静态服务和本地网关。看到 `gateway: ready on port 8000` 后，打开所需页面。

- [图创 AI 主站](http://localhost:8000/dashboard)
- [小哈](http://localhost:8000/lashforge/)
- [无限画布](http://localhost:8000/infinite-canvas/)

## 查看状态、重启与停止

```powershell
.\.venv\Scripts\python.exe scripts\local_services.py status
.\.venv\Scripts\python.exe scripts\local_services.py restart
.\.venv\Scripts\python.exe scripts\local_services.py stop
```

如需只重启主站，使用 `restart --service main`。各服务的输出和错误日志在 `logs` 目录。启动时如果提示 `Port 8000 is already in use`，先停止占用该端口的旧启动任务，再执行启动命令。

服务器启动方式见 [Docker 单容器部署](单容器部署.md)。
