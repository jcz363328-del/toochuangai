# 赛狐广告监控前端

本页面读取全店铺广告监控 JSON，支持“全部店铺 / 单店铺”切换，展示调控建议、规则、活动和每日表现。不同币种分组显示，绝不直接相加。审核与暂缓状态仅保存在当前浏览器，不会调用广告写接口。

单店诊断通过本地 `4174` 服务读取按活动分片的持久化快照。快照过期时页面先展示最近成功数据，后端刷新完成后自动更新；前端不会直接访问赛狐 API。

## 手动运行

双击 `run-dev.cmd`，然后打开 <http://127.0.0.1:4173/>。

## 更新数据

```powershell
npm run sync:data
```

正式监控成功后会原子更新 `public/data/ads-monitor.json`。上面的命令用于手工重同步，只接受最新的 `meta.mode=live` 文件；如需明确同步演示数据，必须额外传 `--allow-demo`。

## 校验

```powershell
npm run build
npm run test:sites
```
