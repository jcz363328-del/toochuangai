真实写入必须同时通过的门禁

任何一项不满足都应保持 Dry-run 或阻断。

数据证据

live + 36 小时内、data_status=complete、成熟源 SHA-256 不变、同一基线实时层 fresh + NO_OBJECTION。

对象与数值

只允许 USD、单店单对象、enabled 且正常投放；拒绝 text: 合成 ID；单次变化不超过 10%。

人工授权

冻结计划未过期、--confirm 精确等于 plan_id，并显式设置写入总开关；默认永远不写。

MCP 预检

tools/list 必须包含所需读写工具；inputSchema 摘要一致；写前重新读取当前竞价并与计划一致。

防重复

跨进程锁、写前原子审计占位、同一对象 48 小时冷却，共同阻止本机重复提交。

写后核验

successIds 必须唯一包含目标且 failList 为空；随后再次读取竞价确认。结果不确定时记为 UNKNOWN 并禁止重试。
